# PROMPT — massage_v1 (единый список задач)

Проект: `massage_v1` — сайт баночного массажа (Душанбе).
Стек: React 18 + Vite + Tailwind + MUI + framer-motion + react-icons + Supabase (auth, admin-панель).
Репозиторий: https://github.com/safarovmurod/massage_v1 · Деплой: Vercel.
Язык кода: **JSX (без TypeScript)**. Анимации: **только framer-motion** (anime.js не добавлять).
Тексты — во всех трёх языках: **RU / TJ / EN** (`src/lib/i18n.js`).

---

## 1. Hero (первая секция)

- Сделать **фоновое видео на всю секцию** (full-bleed), тема — массаж / спа / банки.
- Видео: локальный файл в `public/video/`, `autoPlay muted loop playsInline`, `preload="metadata"`, атрибут `poster` (картинка-заглушка).
- Поверх видео — тёмный градиентный overlay, чтобы текст читался в light и dark теме.
- Мобильная версия: видео тоже работает, но вес маленький; если браузер не проигрывает — виден poster. Проверить PC + мобильный.

- Композиция — аккуратная, профессиональная, без «дешёвого» вида. Мобильный текст не должен налезать на нижнюю навигацию.

## 9. Анимации

- Реализация — framer-motion. Без дёрганья, без бесконечных отвлекающих эффектов, `viewport={{ once: true }}`.
